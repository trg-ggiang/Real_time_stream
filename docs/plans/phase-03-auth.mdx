## Chẩn đoán lỗi tạo meeting 2026-11-08

Supabase REST dùng bởi backend truy cập được các bảng/cột liên quan, nhưng API schema không công bố RPC `create_meeting_with_host_member`; đây là nguyên nhân lỗi `PGRST202`. Thêm migration chỉ tạo RPC và cấp EXECUTE cho `service_role`, không tạo bảng hay sửa dữ liệu. RLS catalog chưa được kiểm tra trực tiếp; migration dùng definer có giới hạn. Chưa áp dụng migration. [Work log](/work-logs/2026-11-08-11-phase-03-meeting-rpc-diagnosis).

## Hoàn thiện hợp đồng RPC 2026-11-08

RPC nhận ID người dùng từ `public.users.user_id` sau khi JWT ứng dụng được xác minh, tự sinh ID/mã meeting/session, và trả về meeting cùng session. NestJS đọc kết quả có cấu trúc và phân biệt lỗi RPC, permission, FK, unique, table và column. Unit tests chưa chạy; migration và ghi Supabase thật vẫn chờ. [Work log](/work-logs/2026-11-08-12-phase-03-meeting-rpc-contract).

## Đồng bộ và chẩn đoán RPC tạo meeting 2026-11-08

Lời gọi backend dùng đúng chữ ký 4 tham số; kiểm tra REST/OpenAPI trực tiếp trả 200 nhưng không công bố RPC, xác nhận function chưa được cài trên project. Migration hiện dọn mọi overload an toàn bằng `RESTRICT`, tạo chữ ký chuẩn, giữ quyền EXECUTE chỉ cho `service_role` và reload PostgREST. Backend tests passed. Chưa áp dụng migration do phiên này không có kênh SQL, nên tạo dữ liệu thực và trạng thái RLS/EXECUTE vẫn cần xác minh. Phase 03/04/05 In Progress.

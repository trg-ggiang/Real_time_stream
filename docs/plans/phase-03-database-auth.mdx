## Quyết định và giới hạn

- Không sửa schema hoặc áp dụng migration cũ. Backend không còn phụ thuộc `meetings.livekit_room_name`, `meetings.status`, `max_participants` hay `allow_self_unmute`.
- Mute không được duy trì qua reconnect theo quyết định mới nhất.
- Khi tắt waiting room, request đang chờ vẫn giữ trạng thái pending; cài đặt mới áp dụng cho lượt join sau.
- RRULE hiện hỗ trợ FREQ daily/weekly/monthly/yearly với các trường phổ biến; các field/tổ hợp khác bị từ chối. Cần so với format mà client/DB thực tế sử dụng.
- Chưa chạy automated tests hoặc kết nối Supabase/LiveKit. Backend/frontend typecheck và frontend build đã qua.

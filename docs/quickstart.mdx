Node.js 22.12+ và npm 10+. Chạy `npm install` tại root. Phiên triển khai đã kiểm tra Node 22.23.2 và npm 10.9.8.

`backend/.env` và `frontend/.env` đã được tạo cục bộ, không được Git theo dõi. Trên máy mới, chỉ copy `.env.example` khi chưa có `.env`. Điền `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` ở backend. Supabase và Socket.IO chưa dùng trong Module 1.

Chạy hai terminal từ root: `npm run dev:backend` và `npm run dev:frontend`. Mở `http://localhost:5173` hoặc `http://127.0.0.1:5173`. Để trống VITE_API_URL để dùng API proxy; API_PROXY_TARGET mặc định http://127.0.0.1:3000. API liveness: `http://localhost:3000/api/health`. Backend vẫn chạy khi thiếu credentials nhưng token endpoint trả 503.

Kiểm tra: `npm run typecheck`, `npm test`, `npm run build`. Sau build: `npm --workspace backend start`. Preview frontend: `npm --workspace frontend run preview` (cổng 4173, hỗ trợ API proxy cùng origin).

[Hướng dẫn Module 1](/modules/module-01-media-poc) có hợp đồng API, cấu hình HTTPS khi thử hai thiết bị và checklist nghiệm thu còn chờ.

Docs dùng MDX/Mintlify, chưa cài/chạy CLI docs.

## Chuẩn bị đưa lên Git

Chỉ chia sẻ mẫu `.env.example` với key/secret trống; mỗi thành viên nhận credentials development riêng qua trình quản lý mật khẩu có chia sẻ hoặc kênh mã hóa riêng. Không commit `.env`, khóa riêng hoặc logs. `.gitignore` không tác động tới file đã tracked và không bảo vệ key hardcode trong source. Nếu key đã lộ, thu hồi/thay key.

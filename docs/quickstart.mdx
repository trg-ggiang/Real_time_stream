## Cài và cấu hình

Node.js 22.12+ và npm 10+. Chạy `npm install` tại thư mục gốc.

Tạo `backend/.env` với `SUPABASE_URL`, `SUPABASE_SECRET_KEY` và `JWT_SECRET` dài ít nhất 32 ký tự. Để tham gia họp, bổ sung `LIVEKIT_URL`, `LIVEKIT_API_KEY` và `LIVEKIT_API_SECRET` của nhóm. Phiên họp động dùng mặc định `POC_ENABLED=false`.

Trong `frontend/.env`, giữ `VITE_API_URL=` để Vite proxy `/api` và `/socket.io` về `http://127.0.0.1:3000`. Chat kênh cần schema mở rộng CLB và migration đính kèm. Xem thứ tự và postflight ở [README](../README.md).

## Chạy trên máy

Chạy `npm run dev:backend` và `npm run dev:frontend` trong hai terminal ở thư mục gốc. Mở `http://localhost:5173`. Kiểm tra API qua `http://127.0.0.1:3000/api/health`. Đăng nhập, hoàn thiện hồ sơ, rồi mở Không gian sinh hoạt bằng tài khoản đã tham gia CLB.

Chạy `npm run typecheck`, `npm test` và `npm run build` khi cần xác minh bản hiện tại. Sau build, dùng `npm --workspace backend start` và `npm --workspace frontend run preview` để thử bản build ở cổng 4173.

## Thử qua HTTPS

Chạy `npm run tunnel` và mở URL ở dòng `UniCircle HTTPS:`. Chọn buổi họp rồi bấm **Sao chép link buổi**. Quick Tunnel dùng địa chỉ tạm và cần máy đang chạy. [Hướng dẫn tunnel](/modules/https-tunnel)

Giữ `.env` và credentials trên máy. Chia sẻ cấu hình development qua kênh riêng của nhóm.

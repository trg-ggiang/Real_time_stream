## Hiện trạng 23/11/2026

uniCircle dùng React/Vite, NestJS, Supabase và LiveKit Cloud. Chat kênh CLB dùng Socket.IO và tải bù qua HTTP, hỗ trợ ảnh, tệp riêng tư và link bấm được. Chat trong cuộc họp dùng socket riêng theo phiên. Người đang họp có thể thu nhỏ để nhắn tin trong CLB hoặc mở Picture-in-Picture trên trình duyệt hỗ trợ.

Phase 05 vẫn **In Progress**. Bản tích hợp thu nhỏ và PiP đạt 204 test frontend, build và kiểm thử Chrome mô phỏng. Ca LiveKit Cloud hai thiết bị thật chờ nghiệm thu. [Work log](/work-logs/2026-11-23-09-phase-05-meeting-picture-in-picture) · [Checklist tunnel](/modules/https-tunnel).

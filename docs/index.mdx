## Hiện trạng 25/11/2026

uniCircle dùng React/Vite, NestJS, Supabase và LiveKit Cloud. Chat kênh CLB dùng Socket.IO và tải bù qua HTTP, hỗ trợ ảnh, tệp riêng tư và link bấm được. Chat trong cuộc họp dùng socket riêng theo phiên. Người đang họp có thể về Không gian CLB để nhắn tin, dùng thanh trạng thái để mở lại phòng hoặc mở Picture-in-Picture trên trình duyệt hỗ trợ.

Phase 05 vẫn **In Progress**. Bản cập nhật thanh trạng thái và PiP đạt 207 test frontend, build và kiểm thử Chrome mô phỏng. Ca LiveKit Cloud hai thiết bị thật chờ nghiệm thu. [Work log](/work-logs/2026-11-25-01-phase-05-meeting-call-status) · [Checklist tunnel](/modules/https-tunnel).

## Hiện trạng 19/11/2026

uniCircle dùng React/Vite, NestJS, Supabase, LiveKit Cloud và Socket.IO. Có khám phá công khai, auth/hồ sơ, trang cá nhân, quản lý CLB, admin và họp theo phiên. Workspace đã nối kênh thật, chat HTTP và các cuộc họp gắn CLB. Chat trong phiên họp dùng Socket.IO.

Phase 04 vẫn **In Progress**. Lượt rà đạt 44 test backend và 94 test frontend, browser với API mô phỏng và đối chiếu quyền kênh chỉ đọc trên Supabase. Xem [work log mới nhất](/work-logs/2026-11-19-07-phase-04-workspace-chat-enter) và [luồng workspace](/design/phase-04-club-workspace).

## Desktop interface

The desktop form panel and photo panel use a 1:1.5 split (40% and 60%). The form itself stays up to 480px wide; the photo covers the full height and width of the right panel and crops naturally with object-fit: cover. Switch login/register on the same page; email stays while password clears on mode changes. Light/dark/system controls apply to auth, and the layout collapses to one column below 768px. Inputs provide inline errors and password visibility, while pending requests prevent duplicate submissions. Session persistence, endpoints and DB requirements above are unchanged.

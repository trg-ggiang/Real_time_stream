## Quyết định và lý do

Một app NestJS ở cổng 3000, API chung prefix /api. Auth dùng NestJWT/bcrypt với bảng users có sẵn của Hải; không chuyển sang Supabase Auth. JWT ứng dụng và token LiveKit tách biệt. Chỉ giữ token trong memory, chưa refresh/revoke server-side. Giữ giới hạn PoC production và fixed room.

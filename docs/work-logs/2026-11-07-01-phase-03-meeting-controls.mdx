## Decisions and limits

The provided schema lacked a per-meeting capacity field and microphone self-unmute policy, so the migration adds `max_participants` (default 20 for existing rows) and `allow_self_unmute` (default true). The backend expects the Supabase Auth user UUID to match `users.user_id`. Capacity depends on attendance rows; a browser that disappears without calling leave can hold a seat until a future LiveKit webhook/cleanup process updates `left_at`.

The legacy static-room PoC token endpoint remains separate and does not grant access to created meetings. Signup/login UX and frontend meeting controls are not implemented here.

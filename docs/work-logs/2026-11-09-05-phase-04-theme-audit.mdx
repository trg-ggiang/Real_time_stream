## Objective

Review the whole frontend for light/dark conversion defects, particularly settings menus.

## Findings and completed changes

- meeting-theme.css had stacked overrides and incomplete SDK foreground/control variables. Replaced them with one semantic palette shared by page, form, status, native dialog, account panel and media controls.
- MediaDeviceMenu selection uses data-active, not the lk-active class previously targeted. Selected devices now get explicit foreground/background colors; headings retain full opacity; menu width and wrapping are bounded on mobile.
- Clicking the gear SVG could trigger SDK outside-click handling because the target was a descendant rather than the button. Decorative control SVGs no longer receive pointer events, so the device menu stays open.
- Button color transitions briefly mixed old-theme text with new-theme backgrounds. Removed color interpolation during theme changes, preserving transform-only interaction transitions.
- Auth previously used a separate unsaved system/light/dark selection and green-tinted surfaces. Auth palette now matches white/turquoise and neutral charcoal themes. Selection is shared with meeting preferences, restored on logout/reload, and synced across tabs. System preference is followed when no explicit setting exists; HTML color-scheme and theme-color match.
- Added automated palette contrast regressions and auth theme persistence coverage.

Changed files: meeting-theme.css, meeting.css, auth.css, AuthApp.tsx/test, use-meeting-theme.ts and theme-contrast.test.ts. No BE/DB changes.

## Checks and evidence

- Final frontend build/typecheck passed. All 38 frontend tests passed. Existing media chunk-size warning remains.

- Custom computed-style scan found zero text-contrast failures or horizontal overflow in those 40 final states. Text threshold: 4.5:1 (3:1 for qualifying large text). Disabled controls were exempt. Palette tests also enforce 3:1 input-border contrast. This is targeted verification, not a claim of complete accessibility compliance.

## Công việc hoàn thành

Thay admin ở landing bằng shell /admin riêng, overview số liệu DB, queue phân trang/tìm kiếm/lọc server, detail độc lập và quyết định có lý do/phiên bản. Tách backend admin module và frontend admin pages. Bỏ insert/delete membership bù trong approve cũ; kiểm tra cấu trúc CLB và conditional UPDATE pending/version. Chuyển menu/hash cũ, bảo vệ role/profile phía backend, dùng shared account mutation.

Không migration, seed, ghi DB live, cấp role, commit hoặc push. Giữ thay đổi các phase trước. Quyền admin không tự là quyền chủ nhiệm một CLB.

## Quyết định / giới hạn

Approval dựa trigger khởi tạo CLB đã tồn tại, không tạo membership khi xét duyệt. Conditional UPDATE chống quyết định trên bản cũ; không claim toàn bộ quyền/structure checks là transaction row-lock. Không thêm revision, suspend action, user management hoặc audit table ngoài scope. Media hai thiết bị và Supabase writes thật chưa nghiệm thu.

## Objective and implementation

User requested the matching header section label to turn blue, underline and scale 1.15 while scrolling. GuestLanding.tsx tracks three section rectangles against a reading line below the sticky header, using one passive scroll listener batched by requestAnimationFrame. ResizeObserver updates after asynchronous content/section resizing. Listeners, observer and frame are cleaned on unmount. Matching link uses aria-current=location. guest.css applies the accent color, underline and transform scale without reflow; anchor offsets account for the header and reduced-motion disables transitions. No backend/database changes.

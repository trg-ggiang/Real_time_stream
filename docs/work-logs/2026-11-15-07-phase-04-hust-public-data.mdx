## Objective and completed work

User requested real HUST clubs, images and activities researched through Google/social platforms and saved to the connected database. Imported SINNO, HUROS and HBAC: 3 clubs, 3 historical activities (two HUST Robot Arena rounds and HBAAC 2026), and 3 newly compiled introduction posts. Downloaded and optimized 5 actual club photos/logos; no AI-generated club evidence. HUROS uses its logo; activity images are explicitly described as organizer logo/member photograph rather than event photographs.

`data/hust-public.json` stores source links, date precision, original image URLs, local file hashes and image dimensions. Public descriptions/content retain provenance. Facebook requests were throttled/blocked and TikTok robots prevented reading videos; imported facts came from official HUST/club sites and HBAC's public LinkedIn announcement. No claim of collecting Facebook/TikTok post content.

`scripts/seed-hust-public.mjs` uses backend-only environment credentials, dry run by default and an explicit existing owner UUID for writes. It batches inserts, uses deterministic UUIDs, ignores duplicates, preserves existing published records and resumes only drafts whose title, text and owner still match the manifest. REST batches across different tables are not a single transaction; failure stops processing and rerun can resume.

Existing account named Tài khoản Demo was used for internal ownership/review metadata; no account, password, role, schema or RLS change. Review notes identify imported reference content, not actual club administration. Database triggers assign publication timestamps. The frontend activity section now has a general discovery heading and displays Đã kết thúc on completed cards.

Early insert attempts were rejected by DB constraints without creating rows: clubs requires `published`, publication metadata is required, activities use `onsite`/`hybrid`, and content must transition `draft` → `pending_review` → `published`. The completed importer follows these requirements. Three activities temporarily remained drafts until the corrected run published them; final view checks confirm none remain hidden.

A temporary shell-based UI text replacement produced garbled Vietnamese; corrected with a UTF-8 patch before build/browser verification. No garbled replacement remains in the changed JSX.

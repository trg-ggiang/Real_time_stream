## Mục tiêu và phạm vi được giao

Khi nhấn Phòng họp hoặc Home action, mở trang họp riêng trong tab mới theo mẫu URL `/meeting/{id}`, giữ session an toàn và dùng LiveKit room tương ứng.

## Công việc hoàn thành

- Mục Phòng họp và action Home mở tab mới ở `/meeting/new`; FE tạo UUID v4 rồi thay URL thành `/meeting/{uuid}`.
- Tạo layout họp toàn màn hình, tự xin token/kết nối và bật camera/microphone; LiveKit controls gồm camera, mic, chia sẻ màn hình, rời phòng.
- Đổi auth sang cookie HttpOnly/SameSite=Lax, thêm restore `/api/auth/me` và logout xóa cookie; JWT không trả vào FE hoặc URL.
- Thêm endpoint LiveKit xác thực cho UUID room riêng; room ID là định danh, chưa phải ACL membership.
- NestJS production phục vụ FE build và fallback SPA; `/api/*` được giữ riêng.
- Cập nhật test FE/BE, tài liệu route/auth và hướng dẫn production.

## Quyết định và lý do

Tab mới theo ảnh mẫu cần duy trì auth mà không đặt JWT vào URL. Dùng cookie HttpOnly; FE chỉ đọc user từ `/api/auth/me`. Tạo ID UUID phía FE và BE cấp quyền token cho room ID đó. UUID không thay cho danh sách thành viên hoặc phân quyền phòng.

## Blocker và việc chưa hoàn thành

- Production HTTP smoke chưa có kết quả do lệnh bị ngắt.
- Cần chạy lại workspace checks sau thay đổi chẩn đoán camera.
- Browser tích hợp kiểm tra quyền camera/microphone đang là denied; chưa kiểm tra được media thực trong browser đó.
- Dynamic room ID chưa có membership/authorization; bất kỳ user đã đăng nhập nào có thể xin token cho ID phòng.

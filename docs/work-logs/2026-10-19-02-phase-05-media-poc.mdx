## Quyết định và lý do

NestJS modular monolith, frontend theo feature; không tạo abstraction tương lai chưa cần. Room/identity/grants do backend kiểm soát; UUID, TTL 300 giây, camera/mic-only, no-store. Dùng @nestjs/throttler thay vì tự viết bộ đếm; limit 10/phút/IP trong memory. Mặc định loopback, CORS đúng origin và từ chối bật PoC không auth trong production.

Giữ token trong memory, AbortController chống request muộn sau Leave/unmount, khóa Join đồng thời. Dùng LiveKit SDK quản lý media/cleanup và lazy load room. Dùng Vitest/jsdom kiểm thử session cancellation/error, Node test runner cho HTTP/JWT với credentials giả. Đã format source bằng Prettier qua npm exec, không thêm formatter dependency.

Chốt Phase 02 theo contract và thứ tự triển khai ghi trong guide; giữ số phase, thực hiện 04/05 trước 03. Không tuyên bố cloud hoạt động chỉ từ token ký offline.

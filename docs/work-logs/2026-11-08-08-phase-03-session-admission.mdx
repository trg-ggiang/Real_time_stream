- Migration `supabase/migrations/202611080001_session_join_requests.sql`: thêm requested_session_id nullable FK vào meeting_members; index yêu cầu theo session, unique active membership để chặn request trùng; transaction và reload PostgREST schema. - backend/test/meeting-admission.test.cjs: regression chờ/duyệt/join, no-waiting, session isolation, xử lý đua approve/deny, expiry, thiếu migration và legacy binding.
